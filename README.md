# Todo Task Manager App

A simple React project designed to demonstrate the practical use of advanced React hooks: `useMemo`, `useCallback`, and `useRef`.

##  Purpose

This app serves as a learning tool for developers who want to understand how to optimize performance and manage references in React components. It showcases:

-  `useMemo` for memoizing expensive calculations
-  `useCallback` for stable function references
-  `useRef` for accessing DOM elements and persisting values across renders

##  Features

-  Add new tasks
-  Delete tasks
-  View task list
-  Optimized rendering using React hooks
-  A counter value to show Memoizing
-  Responsive UI

##  Tech Stack

- React (via Create React App)
- JavaScript (ES6+)
- Material UI (MUI)
